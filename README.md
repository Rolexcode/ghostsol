# GhostSol

A story-led, dark landing page for GhostSol on Solana.

## Direction
GhostSol is treated as an urban legend rather than a generic memecoin template: sightings, a haunted city, an apparition that comes and goes, minimal Solana accents, and the core line **“You saw nothing.”**

## Stack
- Next.js 15
- React 19
- Tailwind CSS
- CSS/SVG animation only — no heavy animation dependency
